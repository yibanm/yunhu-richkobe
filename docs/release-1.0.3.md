# 云湖牢大版 v1.0.3

第三方桌面客户端。本版为体验与协议对齐的集中修复版。

## 新增

- **群二维码分享**：群面板「分享」生成群二维码与分享链接，扫码进群
- **邀请入群**：支持好友/群聊筛选、多选、确认发送
- **全局搜索**：侧栏回车搜人/群/机器人；聊天记录搜索可点击精准跳转（持续高亮框 + 「回到最新」入口）
- **表情合集**：面板按合集分页签；管理页点击表情包展开全部内容并可继续添加；每格显示文件名；右键收藏/重命名
- **群管理补全**：设撤管理员、消息自动删除、入群口令、编辑群资料、群盘重命名删除、第三方网盘挂载增删与页内上传
- **账号页补全**：在线设备、金币明细、好友备注云同步、拉黑
- **锁屏忘记密码**：账号密码或 token 验证身份后重设 PIN
- **发现页**：通讯录新增推荐分区与推荐群浏览

## 体验改进

- **默认主题「科比紫」**：Material 3 质感，全 UI 随主题强调色联动，页面保持深色
- **气泡**：宽度随文本、贴近头像、双方圆角一致、己方淡紫
- **群设置**：右侧固定面板直开直关；成员行「管理」小弹窗集中操作；群成员不再误显禁言
- **图片查看**：滚轮缩放、拖拽平移、双击放大；视频应用内全屏
- **细节**：会话列表小圆角、关闭按钮正圆居中、开窗无闪动、多行输入至少 3 行、长公告可展开、消息三点按钮移除（操作走右键）

## 修复

- 聊天记录搜索不显示内容、跳转不精准
- 消息编辑点击无反应
- 自建表情包裂图、移动端无法识别桌面创建的合集与收藏表情（发送协议对齐官方）
- 搜索跳转后无法返回最新
- 版本号硬编码问题：改为构建期注入，检查更新不再误报自身为旧版

## 平台说明

- Windows / macOS / Linux：桌面客户端，内置服务，双击即用（未签名，安装时请允许）
- 安卓：WebView 方案体验有限，推荐原生实现 [Yhchat_md3](https://github.com/Kauid323/Yhchat_md3) 或 [Murexide](https://github.com/murexide-project/Murexide)

## 数据与隐私

- 登录信息与会话缓存保存在文档目录（默认 `文档/yhchat`，关于页可自定义）
- 退出账号清除全部本地凭据；个人偏好保留
