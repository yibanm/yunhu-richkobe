# 云湖牢大版 v1.0.1

在 v1.0.0 的 QQ 式界面上做了一轮体验打磨：更顺手、更稳、更像 QQ。

## 这版你会感觉到

- **未读红点不再「阴魂不散」**：打开的会话不会再冒未读气泡；重启后也不会把读过的消息重新标红
- **粘贴图片先预览再发送**：输入框更大，图片可裁剪/旋转、可配一句话；上传有进度条和实时速度；超大小限制会直接告诉你
- **界面层级理顺了**：所有弹窗、菜单、面板不再互相遮挡；确认框换成和应用同风格的弹窗（不再是系统原生框）
- **侧栏更清爽**：右键会话可置顶/免打扰/移组/删除；输入 @ 会弹出群成员列表（可搜索）；表情面板支持表情包分组
- **锁屏**：☰ → 锁定；可用 PIN 或让手机端 App 弹窗确认解锁
- **数据更安心**：登录态和会话缓存存在你的文档目录（可自定义，如 D:\文档\yhchat）；退出账号会清干净本地凭据
- **更多功能**：左侧竖条的宫格入口，可把常用功能常驻到竖条并拖拽排序
- **关于页**：☰ → 关于，有原仓库和本仓库链接，顺手点个 Star ⭐

## 修复

- 群聊创建偶发卡住、失败误报成功
- 文章卡片打不开、带图文章图片不显示
- 安卓端黑屏（构建目标降级 + 启动崩溃可视化提示）
- 若干菜单被遮挡、图标不居中的问题
